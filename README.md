# 🤖 CyberBot — LLaMA 3.1 Assistant IA

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/UI-Streamlit-FF4B4B.svg)](https://streamlit.io/)
[![Groq](https://img.shields.io/badge/Inference-Groq_Cloud-00d4ff.svg)](https://groq.com/)

> **CyberBot** est un assistant intelligent haute performance doté d'une interface immersive style **Cyberpunk**. Il utilise le modèle **LLaMA 3.1** via l'API Groq pour offrir des réponses quasi instantanées.

---

## 🚀 Points Forts
- **Vitesse Éclair** : Inférence propulsée par les LPU de Groq.
- **Interface Immersive** : Design personnalisé via injection CSS (animations glitch, néons, grille dynamique).
- **Architecture Moderne** : Intégration via LangChain pour une gestion fluide des requêtes.
- **Expérience Utilisateur (UX)** : Chat interactif avec bulles stylisées et animations de chargement.

## 🛠️ Stack Technique
- **Langage** : Python
- **Framework IA** : LangChain / ChatGroq
- **Modèle** : LLaMA 3.1 (8B Instant)
- **Interface** : Streamlit + Custom HTML/CSS
- **Gestion Environnement** : Python-dotenv
